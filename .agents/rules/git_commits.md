# Reglas para Generación de Mensajes de Commit (Git)

Cualquier mensaje de confirmación (commit) generado para este repositorio debe seguir estrictamente estas pautas:

1. **Idioma:** Redactar SIEMPRE el título y descripción del commit en **español**.
2. **Formato Conventional Commits:**
   - `feat: <descripción>` para nuevos avances, entregables o características.
   - `fix: <descripción>` para correcciones de errores tipográficos, de formato o de código.
   - `docs: <descripción>` para cambios en documentación, consignas o bibliografía.
   - `refactor: <descripción>` para renombrado de archivos, reorganización de carpetas o mejoras de estilo sin cambiar la funcionalidad.
   - `test: <descripción>` para scripts o pruebas de compilación.
   - `chore: <descripción>` para configuración del repositorio o tareas de mantenimiento.
3. **Estilo:**
   - Iniciar en minúscula tras el prefijo.
   - Ser conciso, claro y no incluir punto final al término del título.
