# ⚡ Generador de PDFs con Typst

Este módulo utiliza **Typst** para generar documentos académicos y reportes ejecutivos con sintaxis simple tipo Markdown.

## 🚀 Cómo ejecutar
```bash
python generar_con_typst.py
```
Generará automáticamente el archivo `ejemplo_typst.pdf`.

## ✏️ Cómo personalizar
Edita el archivo `documento.typ` con tu texto o estructura y vuelve a correr el script.
