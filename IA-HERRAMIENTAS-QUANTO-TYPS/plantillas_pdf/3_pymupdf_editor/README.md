# ✏️ Editor y Manipulador de PDFs con PyMuPDF

Este módulo permite abrir cualquier PDF ya creado, inspeccionar su contenido, extraer páginas, colocar marcas de agua, sellos o firmas digitales sin tener que recompilar el documento original.

## 🚀 Cómo ejecutar
```bash
python editar_con_pymupdf.py
```
Tomará un PDF existente, le agregará un sello / marca de agua de verificación y guardará la copia modificada.

## 💡 Usos habituales
* Unir varios PDFs en uno solo (*merge*).
* Extraer rangos de páginas específicas.
* Buscar y reemplazar palabras clave dentro del PDF.
* Estampar sellos o numeraciones sobre PDFs existentes.
