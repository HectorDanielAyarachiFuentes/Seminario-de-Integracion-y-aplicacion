# 🌐 Generador de PDFs con Playwright (HTML5 + TailwindCSS)

Este módulo utiliza el motor **Chromium de Google** a través de Playwright para convertir código HTML y estilos CSS modernos (como TailwindCSS o Bootstrap) directamente a PDF con precisión absoluta.

## 🚀 Cómo ejecutar
```bash
python generar_con_playwright.py
```
Generará automáticamente el archivo `ejemplo_playwright.pdf`.

## ✏️ Cómo personalizar
Edita el archivo `plantilla.html` directamente con tu diseño o contenido web preferido y vuelve a ejecutar el script.
