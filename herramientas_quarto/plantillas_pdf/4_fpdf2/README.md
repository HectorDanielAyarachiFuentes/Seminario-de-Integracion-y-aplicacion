# 📐 Generador de PDFs con FPDF2 (Diseño Manual por Código)

Este módulo utiliza la librería clásica **FPDF2** con control milimétrico de celdas, líneas, cabeceras dinámicas y numeración de páginas por dos pasadas.

## 🚀 Cómo ejecutar
```bash
python generar_pdf.py
```
Generará el reporte final maquetado en Python puro.
